🦀 servicrab - Manage local server processes with ease

Download servicrab

Servicrab helps you run and monitor background programs on your computer. It acts as a supervisor, ensuring that your local services remain active while you work. If a process stops for any reason, servicrab restarts it automatically. This tool suits users who maintain homelabs or run small development stacks on Windows.

📥 How to install

Follow these steps to set up servicrab on your Windows machine:

  1. Visit the official release page.
  2. Locate the section labeled Assets.
  3. Select the file ending in .exe for Windows.
  4. Save the file to a folder on your computer.

⚙️ Setting up your services

Servicrab reads a simple configuration file to know which programs to monitor. You create a text file that lists the path to your executable files. You then point servicrab to this file when you launch the application. This ensures that every program you define stays running in the background. You do not need to check these programs manually.

🛡️ Why use a process supervisor?

Computers often run many background tasks. Sometimes these tasks crash or close without notice. A supervisor watches these tasks constantly. When a task closes, the supervisor restarts it immediately. This creates a stable environment for your web servers, databases, or automation scripts. You gain peace of mind knowing your services stay online.

🖥️ System requirements

Servicrab works on Windows 10 or Windows 11. It requires no heavy dependencies or complex installations. Because it uses the Rust programming language, it consumes very little memory. You can run it alongside your primary applications without slowing down your system.

📖 Common questions

Do I need to program? No. You only need to write a simple text file with the names of the programs you want to watch.

Does it run at startup? You can add servicrab to your Windows startup folder if you want it to begin managing your services as soon as you log in.

Is it safe? Yes. Servicrab performs specific tasks to maintain your processes. It does not modify your operating system files or registry.

🚀 Running your first process

Open your command prompt or terminal in the folder where you saved the servicrab file. Type the name of the file followed by the path to your configuration file. Servicrab will output the status of each process it tracks. If you see a green status light, your process is live. You can minimize the window and continue your work.
